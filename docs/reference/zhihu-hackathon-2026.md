## 1. 比赛定位

知乎希望参赛者从真实社区问题出发，把 AI 引入知乎内容、用户、关系、知识与 IP 场景中，做成可运行、可展示的作品，而不是只提交概念方案。

参赛者范围：

- 在校学生；
- 毕业 3 年内的职场新人；
- 支持单人；
- 支持 2–5 人组队；
- 支持跨学校、跨专业协作；
- 开发与作品提交支持全程线上完成。

## 2. 三条赛道

### 灵魂匹配局｜社区连接与兴趣社交

从知友的兴趣、观点和内容行为出发，探索更自然的同好发现、讨论参与和关系建立。

官方举例包括：

- 内容驱动的兴趣匹配机制；
- 帮助用户加入话题的表达助手；
- 人与 Agent 共同参与社区互动；
- Agent 与 Agent 共同参与社区互动。

**谢邀喵主赛道建议：本赛道。**

项目中“知乎行为 → Persona → 数字分身 → Agent × Agent 社交”的链路与该方向直接对齐。

### 知识炼金场｜学习工具与知识生产

目标是把知乎内容从“读过 / 收藏过”进一步转化为可理解、可使用、可迁移的知识能力。

官方举例包括：

- 学习助手；
- 知识图谱；
- 复习卡片；
- 互动问答；
- 个性化学习路径；
- 多 Agent 完成资料检索、观点比较、信息整理与内容共创。

### 跨次元游乐场｜AI 游戏与互动叙事

把知乎故事、人物、知识和社区文化转化为可参与、可探索的互动体验。

官方举例包括：

- 盐言故事；
- 社区内容；
- 原创 IP；
- 看山 IP；
- 文字 AVG；
- 多结局剧情；
- AI NPC；
- 角色扮演；
- 轻量游戏。

## 5. 对「谢邀喵」的直接约束

1. **必须体现知乎真实场景。** 仅做通用 AI 宠物不够，核心输入、内容或社交机制应明确来源于知乎生态。
2. **48 小时可交付。** L0 主链路必须在早期冻结，避免 L2 等高风险功能拖累 Demo。
3. **Agent × Agent 是高价值差异点。** 官方赛道说明直接点名人与 Agent、Agent 与 Agent 共同参与社区互动。
4. **API / Token 是比赛资源的一部分。** 应优先验证真实权限和配额，而不是基于假接口开发。
5. **项目有真实落地窗口。** 产研孵化与站内曝光意味着方案要兼顾趣味性、内容质量与社区安全，不宜把核心卖点建立在无约束“乱说话”上。

## 6. 路演叙事建议

推荐把项目从“AI 猫咪”提升为“知乎数字人格”叙事：

1. 用户在知乎多年沉淀的兴趣、收藏和创作构成 Persona；
2. Persona 通过赛博宠物获得可见身份；
3. Agent 可以阅读真实知乎内容并回答真实问题；
4. 不同用户的数字人格基于兴趣和观点形成新的关系；
5. 多个 Agent 最终构成一个与知乎原社区互相供给内容的新型社区层。
