# 「谢邀喵」页面架构与操作树 v1

> 2026-09-12。视觉方向：Direction C「人格剧场」。长期循环：自主出门 / 回家带回经历。
>
> 本文冻结“哪些东西是页面、页面里放什么、主要 CTA 去哪里、页面之间如何跳转”。不生成图片，不冻结最终美术细节。

---

# 0. 页面设计总原则：先管理注意力，再管理功能

页面不是功能容器。每一屏首先要回答：**用户此刻最应该看什么、感受什么、做什么？**

## 0.1 每屏注意力预算

每个核心页面默认只允许：

```text
1 个第一视觉焦点
1 个核心结论 / 情绪
1 个主 CTA
0–1 个次 CTA
```

其余内容必须后置到：

- 下一屏；
- Drawer / Bottom Sheet；
- 展开后的证据说明；
- 详情页；
- 图鉴 / 历史记录。

**如果一个区块既不改变当前判断，也不帮助当前动作，就不应该出现在首屏。**

典型需要后置的内容：

- 完整成长数值；
- 完整兴趣向量；
- API / 技术说明；
- 多条历史记录；
- 关系全量列表；
- 证据明细；
- 次要统计；
- “为了显得丰富”而添加的装饰卡片。

## 0.2 三层注意力顺序

每页文档与实现都按以下顺序检查：

1. **第一眼：** 3 秒内看到什么？必须是这个页面唯一的主命题。
2. **第二眼：** 用户理解主命题后，需要什么证据或上下文？
3. **最后才看：** 只有主动探索时才需要的详情，默认折叠或进入详情页。

例如 Reveal：

```text
第一眼：我是什么 Persona
第二眼：3 个最能让我觉得“像我”的属性
最后才看：为什么这样判断、原始证据、完整成分
```

## 0.3 不为“页面数量”拆页面

不是每一个状态都拆成独立路由。

**独立页面**只用于：

- 用户心智发生切换；
- 需要浏览器历史 / 分享链接 / 深链；
- 内容结构显著不同；
- 需要独立权限或公开访问。

**页面内状态 / Sheet / Drawer**用于：

- 留出门纸条；
- “为什么？”证据解释；
- OAuth 权限详情；
- Persona 数据不足补充；
- Home 的 `AT_HOME / PREPARING / AWAY / RETURNED`；
- Match 换候选；
- 简短关系变化确认。

目标：首访像一段连续演出，日常像一个活着的小剧场，而不是一组 SaaS 页面。

## 0.4 桌面和手机共享信息架构，但不共享构图

两端使用同一套页面、状态和业务对象，但布局与交互可以不同：

- **手机端：** 单列、拇指可达、底部导航、Bottom Sheet、纵向叙事；
- **桌面端：** 左侧导航 Rail + 中央主舞台 + 条件性右侧上下文；Drawer 优先于 Bottom Sheet；
- 不允许把桌面端做成“手机页面拉宽”；
- 不允许桌面端因为空间更大就塞更多首要信息；
- 核心操作不能依赖 hover；hover 只做增强提示。

详细双端规格见 `docs/product/responsive-attention-spec-v1.md`。

| ID | 页面 | Route | 目的 |
|---|---|---|---|
| P13 | 旅途详情 | `/journey/:id` | 展开一趟 outing 的完整故事 |

## 1.1 核心页面注意力矩阵

| 页面 | 第一眼必须看到 | 唯一主动作 | 必须后置 |
|---|---|---|---|
| P01 Landing | “我在知乎养出了什么？” | 开幕 | 功能列表、技术、成长说明 |
| P02 Consent | 为什么需要公开数据 | 用知乎开始孵化 | OAuth 细节、长隐私文本 |
| P03 Scanning | 当前正在发现什么 | 无，自动推进 | 全量接口状态、完整 evidence |
| P04 Reveal | Persona 身份 | 第一次出门 | Growth、完整兴趣向量、分享 |
| P05 Match | 我和 TA 为什么同频 | 让它们先聊 | Top N、完整匹配维度 |
| P06 Encounter | Persona 之间真的不同 | 想认识 TA / 完成首遇 | 技术链路、无限聊天 |
| P07 Curtain Call | 第一段关系已经形成 | 回我的窝 | 长期玩法教程全集 |
| P08 Home | 它现在在哪 | 与当前 outing 状态对应的一个动作 | 关系全表、Feed、全量 Growth |
| P09 Explore | 最近一次旅途 | 看旅途详情 | 无限推荐流 |
| P10 Encounter Hub | 最近一次重要相遇 | 看这一幕/关系 | 无限匹配池 |
| P11 Atlas | 我现在是什么 + 最近变了什么 | 探索档案分区 | 同时展开所有统计 |
| P12 Public Explore | 这个世界里的 Persona 会做什么 | 我也想养一个 | 公开无限 Feed |

任何页面如果同时出现两个以上“同样抢眼”的主命题，优先删减而不是继续排版。

# 16. P15｜隐私与数据边界 `/privacy`

内容只解决：

- 读取什么；
- 不读取什么；
- 为什么读取；
- 保存哪些结构化结果；
- 不保存哪些秘密；
- 如何退出 / 清理应用侧数据（具体能力按实际实现）。

它是工具页，不进入主导航。
