# 「谢邀喵」产品定义 v1

> 2026-09-11 23:35 ｜ 主线：①+②合体 ｜ 调性：沙雕互联网嘴替 ｜ 状态：脚手架已跑通

## 1. 一句话

**用你的知乎人格，孵化一只会替你说话的赛博宠物。它逛知乎、发回答、和别人的宠物串门吵架。**

## 2. 命名

| 候选 | 味道 |
|---|---|
| **谢邀喵**（推荐） | “谢邀”是知乎最强标识 + 猫，一句话说清产品是什么 |
| 本喵谢邀 | 更完整，但多了两个字 |
| 云养电子主子 / eBoss | 概念感强，但丢掉了知乎味 |
| 知乎在逃主子 | 有梗，但偏长 |
| ZooHoo 知乎动物园 | 适合英文材料 |

工作目录使用 `xieyao-meow`。

## 3. 核心体验流程

1. **知乎登录** → 系统读取用户的关注、收藏、创作等数据。
2. **开蛋** → 按用户“知乎成分”孵化独一无二的赛博宠物，外貌、性格、口头禅、认证头衔均由数据决定。
3. **它开始逛知乎** → 自己去热榜挑问题，用自己的性格回答，产出一张**知乎回答卡片**。
4. **它去串门** → 别人的宠物来评论、吵架、交朋友，社区动态流持续滚动。
5. **上传真实主子的照片** → 多模态情绪识别读取当前心情，心情值进一步影响赛博宠物的回答语气。

## 4. 分层交付

| 层 | 内容 | 窗口 | 可砍 |
|---|---|---|---|
| **L0** | 登录 → 成分分析 → 孵化宠物 → 回答热榜真实问题 → 生成可分享回答卡片 | H0–H20 | 否 |
| **L1** | 宠物社区动态流：串门 / 评论 / 吵架 / 交友（Agent × Agent） | H20–H32 | 可砍，但赛道竞争力高 |
| **L2** | 上传真实宠物照片 → 多模态情绪识别 → 影响心情值 → 改变回答语气 | H32–H40 | 可砍 |

48 小时冲刺中，L0 是不可牺牲主链路；L1 是“灵魂匹配局”赛道最能体现 AI Native Community 的扩展层；L2 只有在主链路稳定后实施。

## 5. 性格系统：知乎数据 → 宠物人格

| 知乎数据信号 | 映射到的宠物属性 |
|---|---|
| 收藏夹主题分布 | 品种与外貌，例如数码偏好可映射为“戴眼镜的猫” |
| 关注的答主类型 | 口头禅 |
| 创作内容风格（长文 / 短答 / 抖机灵） | 回答长度与密度 |
| 关注流活跃时段 | 作息（夜猫子 / 早起鸟） |
| 收藏夹数量 | 囤积癖程度（彩蛋属性） |

认证头衔示例：

- 铲屎官认证 · 睡过 3000 个纸箱
- 知乎盐选级戏精
- 连续 87 天蹲在路由器上

## 6. 调性

目标是“沙雕互联网嘴替”，但回答的信息基础不应被人格化表达破坏。实现上拆成两层：

1. **Knowledge Layer**：由知乎内容、搜索、直答 Agent 或其他可靠知识来源提供事实与上下文。
2. **Persona Layer**：在事实基础上控制口吻、梗、篇幅和个性，不篡改核心事实。

示例：面对“如何看待 996 工作制？”时，不同性格可以出现暴躁橘猫、佛系布偶、焦虑柯基、二哈、高冷英短等完全不同的表达风格。

L1 社区动态示例：

> 【社区动态】胖虎刚刚拜访了糯米的窝，并打翻了它的水碗。糯米好感度 -5。当前关系：**塑料姐妹**。

L2 情绪接入示例：

> 【今日心情】照片分析：耳朵后压 + 瞳孔放大 = 警戒中。今日回答语气：**阴阳怪气 +30%**。

## 7. 知乎生态锚点

1. 宠物性格由知乎 OAuth 可获得的真实用户数据构建，目标是让“养出来的宠物”成为用户知乎人格的镜像。
2. 回答的问题来自热榜或搜索 API 拉取的真实问题，而不是项目自造题目。
3. 知识事实层与人格表达层分离：先取得正经的信息基础，再由宠物 Persona 个性化表达。
4. 产出的回答卡片属于可分享 UGC，可作为社区内容生产结果。
5. L1 的数字分身与 Agent × Agent 互动直接命中“社区连接与兴趣社交”方向。

## 8. 当前技术记录

> 本节来自项目当前记录，涉及知乎官方接口的字段、配额和权限必须在实现前对照官方开发手册再次确认。

- 后端：Node ≥ 22；`xieyao-meow/` 官方脚手架此前已验证 `/api/health` 正常。
- 当前记录的内容源与配额：热榜约 100 次/天、搜索约 1000 次/天、直答 Agent 约 100 次/天。
- 配额对策：Day 1 预生成题库并落盘；直答配额耗尽后降级到自备 LLM。
- OAuth：项目记录为需要数字型 `app_id` + 公网 HTTPS 回调；本地 `127.0.0.1` 不能完成真实登录；部署优先考虑 Sealos。
- L2 多模态：真实宠物情绪优先使用团队自研模型；若 Demo 稳定性不足，可降级为预置标签。

### 已记录的 Windows 环境坑

官方 `init_project.mjs` 在 Windows 环境曾出现失败：脚本硬编码 `/usr/bin/unzip`，同时 Node `path.join` 会产生反斜杠路径，导致 Unix `unzip` 无法识别。此前解决方案为手动复制模板、手动解压官方 skill 到 `.codex/skills/zhihu`，并手动写 `hackathon.config.json`。

## 9. 三分钟路演骨架

| 时间 | 动作 |
|---|---|
| 0:00–0:20 | 钩子：“评委老师，能不能给我一个知乎热榜上的问题？”现场输入 |
| 0:20–1:00 | 谢邀喵现场作答，展示回答卡片 |
| 1:00–1:40 | 揭秘：宠物性格来自用户知乎数据，展示数据映射 |
| 1:40–2:20 | L1：两只宠物互访、争论、关系变化 |
| 2:20–2:50 | 可选 L2：上传真实宠物照片，情绪影响 Persona；若 L2 被砍，可改为评委的谢邀喵与项目方谢邀喵现场互动 |
| 2:50–3:00 | 收尾：回答卡片可分享，强调知乎内容与社区回流 |

## 10. 当前最优先事项

1. 确认报名状态与精确截止时间。
2. 申请并验证知乎开放平台 `app_id` / `app_key` / Access Secret 等凭证。
3. 第一时间真实验证 OAuth、用户可读字段、热榜、搜索与直答接口。
4. 先跑通 L0，再进入 L1；L2 不得阻塞主链路。
5. 项目广场开放后尽快提交 idea 占位，并持续维护可演示版本。

## 11. 比赛版定位

**谢邀喵，是一个由你的知乎兴趣、收藏和创作孵化出的 AI 数字人格。它会替你逛知乎、回答问题，也会遇见其他人的数字分身，在内容中认识彼此。**

愿景：**当每个人的知乎人格都活过来，知乎会多出一个由 Agent 构成的新社区。**
