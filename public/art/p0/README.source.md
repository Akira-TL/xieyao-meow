# 谢邀喵视觉缺口 P0 资产包（两次生成）

本压缩包包含两套生成结果，均已按统一规范重命名，方便直接接入项目或做人工筛选。

## 目录结构

- `set_01_first_generation/`：第一次生成结果
- `set_02_second_generation/`：第二次生成结果

## 文件命名说明

每套都包含以下 8 张：

1. `01_egg_idle.png` — Persona Egg 静止态
2. `02_egg_scanning.png` — Persona Egg 扫描态
3. `03_egg_glowing.png` — Persona Egg 发光态
4. `04_egg_cracking.png` — Persona Egg 破壳中
5. `05_egg_opened.png` — Persona Egg 打开态（中间留空可合成黑猫）
6. `06_room_home_night.png` — Home Room 夜间常驻场景
7. `07_room_empty_night.png` — Home Room 夜间离开场景
8. `08_journey_zhihu_gate.png` — Journey / Explore 入口场景

## 建议使用方式

- 需要严格挑选时，可逐张对比两套结果后择优使用。
- 若希望同一条产品链路内画风更统一，建议尽量整套使用同一 generation。
- 蛋的 5 个状态建议始终来自同一套，以保证壳体形状与斑点分布更一致。
- `room_empty_night` 建议与同套的 `room_home_night` 搭配使用。

## 备注

- 房间与 Journey 图均未烧入可读文本，便于后续 HTML/CSS 动态渲染。
- 蛋素材为透明背景 PNG；房间与 Journey 为常规背景图。
