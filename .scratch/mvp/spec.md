# MVP Spec｜谢邀喵 48 小时冲刺

## 目标

在知乎黑客松 2026 的 48 小时开发窗口内，完成一个可稳定演示的「知乎数字人格」产品：用户授权知乎数据后生成独特 Persona，Persona 能基于知乎真实问题生成个性化回答卡片，并在主链路稳定后加入 Agent × Agent 社交。

## 成功标准

### L0｜必须完成

1. 用户可以完成知乎授权或使用可信 Demo fallback 进入体验；
2. 系统能依据真实或已缓存的知乎用户数据生成“知乎成分”；
3. 系统能生成结构化 Persona；
4. 系统能取得真实知乎问题；
5. Knowledge Layer 能提供问题背景或直答结果；
6. Persona Layer 能在不改变事实基础的前提下完成个性化表达；
7. 最终产出可分享的回答卡片；
8. 主链路在路演环境中具备缓存和降级方案。

### L1｜高优先级扩展

1. 两个或以上 Persona 能基于兴趣相似度和观点差异发生互动；
2. 互动形成可读的社区动态；
3. 至少有一个关系状态或好感度变化机制；
4. Agent 行为不是完全随机，而是能追溯到 Persona 或知乎内容信号。

### L2｜可砍

1. 上传真实宠物照片；
2. 多模态识别宠物情绪；
3. 情绪结果改变 Persona Layer 的回答语气。

## 不在 MVP 内

- 完整宠物养成经济；
- 复杂游戏系统；
- 大规模长期社区模拟；
- 未经官方确认的知乎写入/发布能力；
- 为了视觉完整度牺牲 OAuth、真实问题或回答主链路。

## 关键风险

- 官方开发手册尚未在本仓库中完成全文核验；
- OAuth scope、用户可读字段、接口 endpoint、配额和错误码仍需真实确认；
- 比赛时限短，必须把 API 验证置于 UI 精修之前；
- 官方接口不可用时需要缓存和明确标注来源的 fallback。
