# 05｜Demo 稳定性、降级与路演冻结

Type: task
Status: ready-for-agent
Blocked by: 03, 04

## 目标

在停止新增核心功能后，把比赛提交和现场路演所需链路固化为可重复、可恢复的 Demo。

## 完成标准

- 热榜、搜索、Knowledge Layer 关键结果可缓存；
- 保留至少一组真实请求成功的演示数据；
- 官方接口不可用时有明确 fallback，且 UI 不伪装数据来源；
- OAuth、外部 API、模型调用均有用户可理解的错误态；
- 路演脚本与产品实际行为一致；
- 关键演示流程至少完成多轮端到端演练；
- L2 只有在 L0/L1 稳定后才进入实现，否则明确砍掉。
